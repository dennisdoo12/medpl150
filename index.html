Creativity is about building things that clearly communicate who I am, what I can do, and where I would like to go. I am interested in digital creation because it sits at the intersection of design, technology, and storytelling. Through this class, I would like to further develop a personal website that serves as a central hub for my work resume, and projects I am actively building. In the past, I have built websites before using wordpress. While my website was functional, I want to further my skills in developing a website that is more appealing visually. This will help my website to be more intentional and incorporate more visual aspects. One of the main objectives that I want to complete during this class is a personal website that reflects my professional career. I want the website to showcase my resume, highlight technical and creative projects, and continue to evolve as I continue to gain more experience. I am personally interested in learning how layout, typography, structure, and user experience influence how my content is perceived. Another skill I want to gain from this class is taking better photos. Photos that I have taken are not always at the right angles and lighting so hopefully I can learn how to improve on this throughout this class as well as editing photos that I have already taken. Throughout the course we will be exploring photoshop basics as well so hopefully with this class, I will be able to sharpen my skills and create a website that I can be proud of. I look forward to taking this course and learning more about the digital design world.
